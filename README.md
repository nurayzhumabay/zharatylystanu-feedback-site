# Жаратылыстану ғылымдары факультеті — кері байланыс

Бұл — Vercel-ге жариялауға дайын статикалық сайт.

## Vercel-ге жариялау

1. Осы ZIP архивін ашыңыз.
2. Файлдарды GitHub репозиторийіне жүктеңіз немесе Vercel жобасына импорттаңыз.
3. Build command қажет емес.
4. Output directory ретінде `.` (жоба түбірін) таңдаңыз.

## Кері байланыс формасы

Форма Google Sheets кестесіне қосылған. Жаңа кері байланыс кестеге жазылып, деканның email мекенжайына хабарлама жіберіледі.
